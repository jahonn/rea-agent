# Changelog

All notable changes are documented here. The format follows Keep a Changelog and the project uses Semantic Versioning.

## 0.1.0 - 2026-11-11

### Added

- Portable `rea-agent` Agent Skill with authorization and evidence workflow.
- Claude Code subagent plus Codex and dsh instruction snippets.
- Project and user installation planning for Claude Code, Codex, dsh, and WorkBuddy.
- Dry-run-first installer with shared-path deduplication and overwrite protection.
- Side-effect-free Node.js, npm, and REA CLI readiness diagnostics.
- Investigation record template, JSON Schema, and strict CLI validation.
- Synthetic examples, unit tests, CLI tests, and GitHub Actions CI.
- Architecture, security, contribution, and responsible-use documentation.
